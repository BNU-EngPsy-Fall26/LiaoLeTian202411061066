# 信号检测论交互实验 · 智能手环 PPG 心率监测

> **重生之米之手环养成记 —— 作为智能手环「看见」心跳的日子**

一个零依赖、单页、纯原生 HTML/CSS/JS 的**信号检测论（Signal Detection Theory, SDT）交互式心理物理实验**网站。玩家化身智能手环，在合成的 PPG（光电容积脉搏波）波形中判断「是否存在心跳脉搏信号」，系统自动计算辨别力 d′、判断标准 c / β 并绘制 ROC 曲线。

---

## 一、实验原理

智能手环背面的绿色 LED 向皮肤发射光，光电二极管接收反射光；心脏搏动使血管容积周期变化，反射光随之轻微起伏——这就是 **PPG（光电容积脉搏波）**。

然而运动、环境光、佩戴松紧都会带来噪声。**脉搏「信号」**与**随机「噪声」**难分彼此，玩家必须在不确定中作出二元判断：

|  | 判断「有信号」 | 判断「仅噪声」 |
|---|---|---|
| **确实有信号** | 击中 Hit | 漏报 Miss |
| **实际无信号** | 虚报 False Alarm | 正确拒斥 CR |

每个试次合成一段 **3.2 秒**波形，以约 2.6 秒逐点扫描动画呈现（模拟实时监测）；扫描完毕后波形**仅保留 1.5 秒随即消失**，玩家须凭记忆作出判断。

## 二、实验设计

### 3 种干扰情境 × 15 试次 = 共 45 试次（约 6–7 分钟）

| 情境 | 物理机制 | 合成噪声特征 |
|---|---|---|
| **环境光干扰** | 阳光/灯光从缝隙射入 | 0.1–0.5 Hz 低频基线漂移、灯光残余纹波、光线突变 + AGC 指数恢复 |
| **佩戴问题** | 表带松动、摆臂造成运动伪迹 | 8–15 Hz 宽带运动突发包络（与脉搏频谱重叠）、接触压力跳变、瞬态削波、随机接触丢失 |
| **生理因素** | 低灌注、心率变异、呼吸调制 | 呼吸波、小幅肌电、HRV 逐搏间隔抖动 ±8.5%、心率游走、呼吸对搏出量的幅度调制 |

每种情境 **15 试次**：**10 个含脉搏信号**（脉搏幅度在强、弱两档间随机混合，无需区分强弱）+ **5 个仅噪声**，随机排列。所有噪声统一标定 SD=1，保证跨情境信噪比口径一致。

### 4 档可选难度（信号幅度以噪声 SD 为单位）

| 难度 | 强信号 | 弱信号 |
|---|---|---|
| 简单 | 1.80 | 0.95 |
| 标准（默认） | 1.45 | 0.62 |
| 困难 | 1.10 | 0.45 |
| 极难 | 0.85 | 0.32 |

## 三、功能特性

- **逐次判断**：F = 仅噪声 / J = 有信号（或点击按钮），空格进入下一试次
- **刺激限时消失**：波形扫描后呈现 1.5 秒即清空，强制玩家凭短时记忆作答
- **即时反馈**：每次作答显示击中/漏报/虚报/正确拒斥，并用橙色虚线揭示信号试次中隐藏的纯脉搏成分
- **SDT 指标计算**：每种情境分别计算 P(H)、P(FA)、**d′、c、β**；0%/100% 极值自动采用 log-linear 校正（+0.5/+1），逆正态分布采用 Acklam 算法
- **ROC 曲线图**：3 个情境实测点（●环境光 / ■佩戴 / ▲生理）+ 平均 d′ 等感受性理论曲线
- **d′ 与 c 分组对比柱状图**（Canvas 原生绘制）
- **自动结果解读**：三情境难度排序及其 PPG 物理机制解释，映射真实手环的光学屏蔽、加速度计运动相消、高灵敏度模拟前端等工程手段
- **风趣评价**：按平均 d′ 给出段位头衔（PPG 总设计师 / 临床级读图专家 / … / 量子随机数生成器）与虚报、击中、难度彩蛋吐槽；d′ ≥ 1.5 结语「你已合格，可以开启新生活了」，否则「恭喜你，被报废了，可以继续重开了」，点「我知道了」收起评价后展开技术解读
- **自定义 ID + 本地排行榜**：按平均 d′ 降序（并列比正确率），🥇🥈🥉 展示，成绩存于浏览器 localStorage
- **CSV 导出**：全部 45 个试次的情境、真值、反应、结果类型、心率等明细

## 四、运行方式

本项目**无任何外部依赖、无需构建**，两种方式任选：

**方式一：直接打开**

双击 `index.html` 即可在浏览器中运行。

**方式二：本地服务器（推荐，避免个别浏览器本地文件限制）**

```bash
# Python 3
python -m http.server 8765
# 然后浏览器访问 http://127.0.0.1:8765/
```

建议使用 Chrome / Edge / Firefox 的最新版本。

## 七、核心公式

```
d′ = Z[P(H)] − Z[P(FA)]                          # 辨别力（感受性），越大越敏感
c  = −½ ( Z[P(H)] + Z[P(FA)] )                   # 判断标准，负值宽松、正值严格
β  = φ(Z(H)) / φ(Z(FA))                          # 似然比标准
```

信号检测论的核心洞见：工程手段（光学屏蔽、运动相消、高灵敏前端）本质上是在**提高 d′**；而手环「运动提醒模式 / 省电免打扰模式」之间的切换，则是在给定 d′ 下沿同一条 ROC 曲线**移动判断标准 β**。
